# Dash?
Dash? is a simple fun game made for Jumpstart Haven. 

In this game, you're a smol ball and your one and only objective is to pop as many red balls as possible. Click/Touch and drag to aim and release to shoot. Don't fall in lave and let's see how long you can last.

Download or play the game in browser on itch.io: https://codecookermintz.itch.io/dash
